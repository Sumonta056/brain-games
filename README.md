# Brain Garden 🧠🌱

Short, friendly brain games to relax and sharpen your mind.

- `docs/design.html`: open it in a browser. It's the full working design with all 15 games.
- The Nuxt 4 app is in `app/`. 3 games are ported, and the other 12 follow the same pattern (see CLAUDE.md).

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
```

Docs: `CLAUDE.md` (rules for Claude Code and for you), `docs/functional-requirements.md`, `docs/games.json`.
